# Decisions

This directory holds one dated file per decision or change plan, named `YYYY-MM-DD-short-slug.md`. Separate files let several harnesses record decisions in parallel without merge conflicts. Architecture decisions also get an ADR in `docs/adr/`.

Each entry states what changed, why, what was proposed but not applied, and what is still open.
